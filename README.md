## Tapjacking Demo

**Team Name:** pixJacking  
**Institution:** Universiti Kuala Lumpur – Malaysian Institute of Information Technology (UniKL MIIT)  
**Course:** Ethical Hacking (IKB31603)  
**Semester:** October 2026  
**Project:** Ethical Hacking Tool Development  
**Attack Category:** Mobile Application Attack – Tapjacking

This project was developed by Team pixJacking as part of our Ethical Hacking coursework. Our goal was to build a practical Android demonstration that helps us understand how tapjacking works and how mobile applications can protect users against obscured touch interactions.

We worked on both the demonstration and the defensive side so that the project could show the attack concept while highlighting the importance of Android security mechanisms.
